      How to set this up
      1. On GitHub, create a private repository for the data, for example calorie-log-data, and tick Add a README file.
      2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
      3. Under Repository access choose Only select repositories and pick the data repository.
      4. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
      5. Pick an expiry you are comfortable with, generate the token, and paste it above together with yourname/calorie-log-data.
      6. Repeat the paste on each device. The token is kept only in this browser.
